# 🖥️ Projet : Administration Windows Server & Active Directory

## 📌 Présentation du projet

Ce projet consiste à déployer et administrer une infrastructure Windows Server dans un environnement de laboratoire virtualisé.

L'objectif est de mettre en place un domaine Active Directory afin de centraliser la gestion des utilisateurs, des groupes, des unités organisationnelles (OU) et des stratégies de groupe (GPO).

## 🎯 Objectifs

- Installer et configurer Windows Server.
- Mettre en place un contrôleur de domaine.
- Créer et configurer un domaine Active Directory.
- Organiser les utilisateurs et les groupes.
- Gérer les unités organisationnelles (OU).
- Configurer les stratégies de groupe (GPO).
- Vérifier la résolution DNS et l'authentification des clients.

## 🛠️ Environnement technique

| Outil | Utilisation |
|---|---|
| Windows Server 2025 | Système serveur |
| Windows 11 | Poste client |
| VMware Workstation | Virtualisation |
| Active Directory | Gestion centralisée des utilisateurs |
| DNS | Résolution des noms |
| GPO | Gestion des stratégies de sécurité |
| PowerShell | Automatisation et administration |

## ⚙️ Travaux réalisés

### 1. Configuration du serveur
- Installation de Windows Server.
- Configuration de l'adresse IP statique.
- Installation des rôles AD DS et DNS.

### 2. Configuration Active Directory
- Création du domaine `nithya.lab`.
- Promotion du serveur en contrôleur de domaine.
- Création d'unités organisationnelles (OU).
- Création des utilisateurs et groupes de sécurité.

### 3. Configuration du poste client
- Configuration réseau du poste Windows 11.
- Intégration du poste client au domaine.
- Vérification de l'authentification avec un compte du domaine.

### 4. Tests et validation
- Vérification de la connectivité réseau.
- Tests de résolution DNS.
- Vérification de l'accès au domaine.
- Tests de connexion avec les comptes utilisateurs.
